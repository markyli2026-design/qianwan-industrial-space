# 前湾产业空间云超市

## 公开在线演示

GitHub Pages 自动发布全模拟演示：144 宗程序生成的矩形地块，包含浅色/影像切换、产业浏览、组合筛选、宗地卡片和详情。边界、区块、园区、企业及业务指标全部为模拟，不代表真实宗地或规划成果；后台维护入口关闭，演示不提供服务端保存。

运行 `npm ci`、`npm run build:demo` 即可生成 `dist` 静态网站；构建过程不读取项目真实数据。`main` 分支推送后由 GitHub Actions 发布到 Pages。公开仓库也不包含本机业务目录 `public/data.js`，仅提供 `public/catalog-example.js` 模拟目录样例。

## 本地完整系统

基于第二版蓝白原型开发的本地可运行系统，采用 MapLibre GL JS 与 OpenStreetMap 浅色矢量底图，接入项目 data 目录的工业用地 Shapefile。

底图样式位于 `public/basemap-light.json`：浅灰陆地、淡蓝水系、低对比道路；不展示兴趣点、建筑纹理和密集地名。支路在放大后出现，宗地业务图层保持独立。矢量服务地址可在该文件中替换。

地图左上方可切换“浅色地图 / 卫星影像”。影像使用 Esri World Imagery 在线服务，首次切换时按需加载，保留当前视角、筛选和选中宗地。影像模式降低宗地填充透明度、加粗边线，并以浅黄色强调选中边界。切回浅色地图恢复原有样式；三个地图页面共用本次会话的底图选择。影像非实时数据，实际清晰度与拍摄时间随地区变化，来源署名显示在地图右下方。

## 启动

代码仓库只包含应用源码，不包含真实宗地数据、生成后的宗地 JSON、本地维护记录或运行截图。克隆仓库后，将工业用地数据库的 `.shp`、`.shx`、`.dbf`、`.prj`、`.cpg` 文件放入仓库目录同级的 `data` 文件夹，文件名保持为“前湾工业用地数据库”。

需要 Node.js 22 或更高版本。在本目录执行以下命令。

```powershell
npm ci
npm run import:data
npm start
```

浏览器打开 http://127.0.0.1:43880 。开发数据已导入后，日常运行执行 `npm start` 即可。地图底图需要网络连接，MapLibre 和 Turf 静态文件随数据导入复制到本地。

## 已实现

- 产业规划、土地家底、企业选址和数据维护四个页面。
- 真实宗地面、地图点击、清单定位、范围缩放、统计筛选、产业及面积等组合条件。
- 清单与详情等高并排，各面板可折叠。卡片纵向滚动。
- 后台修改通过本地接口保存，服务器重启后保留。并发修改使用版本号检查，冲突会提示刷新。
- 详情中可查看字段来源和原始 DBF 台账。周边配套模拟点与线使用真实地理坐标，并计算到宗地边界的最近距离。

## 数据口径

源数据为 `../data/前湾工业用地数据库.shp` 和配套 DBF，共 1,206 宗。导入保留原始 Polygon/MultiPolygon 几何结构，包括内环，不简化或重画地块。坐标系依据 PRJ 为 CGCS2000 经纬度（EPSG:4490），按经纬度加载到 Web Mercator 地图。未施加 GCJ-02 偏移，本版本用于地块浏览，不作测绘级坐标成果。

宗地索引、权利人、坐落、用途、实际面积、供应面积、登记面积及原始供地标志来自台账。亩数由平方米换算。源日期早于1900年的占位值归为空。字段截断的原值保留在台账详情，供后续业务核对。

缺失的区块、园区、产业、企业、审批、建设界面、可用性和配套按固定规则生成模拟数据，并逐字段标记“模拟补充”。六个区块的关联按位置分组，仅用于演示筛选，不代表正式规划归属。地图展示真实宗地按模拟归属着色，正式规划边界需后续接入。原始供应字段“是/否”保持映射为“已供/未供”。

地上企业采用明确带“模拟”名称的记录，未将权利人自动认作在营企业。附带的厂中厂清单尚未建立可靠宗地映射，本次未自动关联。模拟周边设施只用于展示交互与距离计算。

维护修改保存在 `server/state/edits.json`，原始 Shapefile/DBF 保持作为来源。重新导入使用相同 OBJECTID 标识，保留已保存的修改。源数据换版前需核对 OBJECTID 是否继续对应同一宗地。

## 验证与部署范围

`npm test` 检查全部宗地边界、原始核心字段保留、模拟来源、后台持久化、并发版本冲突与禁止修改几何。

GitHub Actions 运行不依赖业务数据的代码与底图样式检查，并构建发布独立的静态演示；完整数据测试在已导入数据的本机运行。本地完整应用依赖 Node.js 后端，不能将 `public` 目录直接作为 GitHub Pages 完整系统发布。

服务默认绑定本机 127.0.0.1，当前版本供本地评审及功能联调。正式多人部署需要配置身份认证、角色权限、备份和部署网络。外部招商接口与正式审批数据尚未接入。

OSM 底图按需请求，保留版权标注和浏览器正常缓存，不预下载瓦片。正式部署可按服务容量切换商业瓦片服务或配置天地图 Key。参考 [MapLibre 文档](https://maplibre.org/maplibre-gl-js/docs/) 与 [OSM 矢量瓦片使用要求](https://operations.osmfoundation.org/policies/vector/)。
